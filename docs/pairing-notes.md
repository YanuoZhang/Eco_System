## ✅ Reflections & Observations

- **What worked well:**  
  - Clear task division across epics made pairing focused and effective.  
  - Real-time feedback improved design-logic consistency.  
  - GitHub branches supported smooth collaboration and merge flow.

- **Challenges:**  
  - Meeting fatigue after back-to-back sessions.  
  - Merge conflicts occasionally delayed handoffs.  
  - Some decisions lacked documentation during fast iterations.

- **Suggestions for future iterations:**  
  - Time-box pairing sessions to 2 hours.  
  - Standardise pairing logs (LeanKit or GitHub Issues).  
  - Use shared planning board to clarify pairing intent per task.
